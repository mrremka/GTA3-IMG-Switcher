## ✨ О программе

**GTA3 IMG Switcher** — небольшая Windows-утилита для игроков, которые используют несколько вариантов `gta3.img` в GTA San Andreas.

Вместо постоянного копирования огромного архива программа хранит один неактивный профиль рядом с `models` и быстро меняет файлы местами.

### Возможности

- ⚡ Почти мгновенное переключение на одном диске
- 🎨 Тёмный интерфейс и плавная анимация кнопок
- 🇷🇺 Русский и 🇬🇧 английский интерфейс
- 🏷️ Свои названия двух профилей
- 🔍 Автоматическое определение активного профиля
- 🛡️ Проверки безопасности перед переключением
- 🎮 Блокировка переключения при запущенной GTA
- ↩️ Автоматический откат при ошибке второго перемещения
- 🧾 Локальные технические логи
- 🩺 Создание диагностического отчёта одной кнопкой
- 📂 Быстрое открытие папок профилей
- 💾 Настройки в `%AppData%\GTA3 IMG Switcher`
- 🔒 Ничего не отправляется автоматически

## 📁 Как это работает

Если активен Профиль A:

```text
GTA San Andreas/
├── models/
│   └── gta3.img
├── gta3_MODDED/
│   └── (пусто)
└── gta3_VANILLA/
    └── gta3.img
```

После переключения на Профиль B:

```text
GTA San Andreas/
├── models/
│   └── gta3.img
├── gta3_MODDED/
│   └── gta3.img
└── gta3_VANILLA/
    └── (пусто)
```

Содержимое `gta3.img` программа не редактирует — только перемещает файл.

## 🚀 Быстрый старт

1. Соберите или скачайте `GTA3 IMG Switcher.exe`.
2. Запустите программу.
3. Выберите `GTA San Andreas\models`.
4. Программа создаст `gta3_MODDED` и `gta3_VANILLA`.
5. Положите неактивный `gta3.img` в нужную папку профиля.
6. При желании переименуйте профили.
7. Переключайте их одной кнопкой.

> [!IMPORTANT]
> `gta3.img` должен лежать только в одной из двух папок профилей. Архив внутри `models` считается активным.

## 🧾 Логи и сообщения об ошибках

Лог хранится локально:

```text
%AppData%\GTA3 IMG Switcher\logs\latest.log
```

Кнопка **«Сообщить о проблеме»** создаёт папку с:

- `diagnostics.txt`
- `latest.log`

Папка откроется автоматически, а текст диагностики скопируется в буфер обмена.

**Ничего не отправляется автоматически.** Пользователь сам решает, прикреплять ли файлы к GitHub Issue.

```text

4. Запустите GTA3 IMG Switcher.exe
```

## 💻 Требования

- Windows 10 или 11
- GTA San Andreas со стандартной папкой `models`
- .NET Framework 4.x для сборки из исходников

## 🔐 Приватность

Программа не использует аналитику, телеметрию, трекеры и автоматическую отправку данных.

В диагностическом отчёте могут быть:

- версия программы;
- версия Windows;
- состояние файлов;
- названия профилей;
- путь к игре, при этом путь внутри профиля Windows заменяется на `%USERPROFILE%`;
- технические сообщения ошибок.

Перед публичной отправкой отчёт можно самостоятельно просмотреть.
