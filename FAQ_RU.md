# Частые вопросы

## Программа работает только с какой-то одной сборкой GTA?
Нет. Названия профилей полностью настраиваются. Можно использовать Vanilla/Modded, SA-MP/Singleplayer, Original/HD, Polyak/Originals или любые другие варианты.

## Она изменяет содержимое gta3.img?
Нет. Программа только перемещает файл целиком между папками.

## Почему переключение такое быстрое?
Папки профилей создаются рядом с `models`. Если всё находится на одном диске, Windows обычно меняет расположение файла без полного копирования его содержимого.

## Можно сделать больше двух профилей?
В v1.0 — нет. Для первой публичной версии специально оставлены два профиля, чтобы определение состояния файлов было максимально простым и безопасным.

## Можно переименовать профили?
Да. Нажмите **«Названия профилей»**.
Соответствующие папки профилей тоже будут переименованы безопасным для Windows способом.

## Можно менять язык программы?
Да. Кнопка RU/EN находится сверху справа.

## Где хранятся настройки?
`%AppData%\GTA3 IMG Switcher`

## Где лежат логи?
`%AppData%\GTA3 IMG Switcher\logs\latest.log`

## Логи отправляются автоматически?
Нет. Программа ничего сама не отправляет.

## Что прикладывать к сообщению об ошибке?
Нажмите **«Сообщить о проблеме»** и приложите `diagnostics.txt` и `latest.log`.

## Работает ли программа с Mod Loader?
Она отвечает только за `gta3.img`. Остальные моды и загрузчики программа не меняет.

## Нужно закрывать GTA?
Да. Переключение при запущенной GTA блокируется.

## Почему программа не сверяет SHA-256?
Ранние версии долго читали огромный `gta3.img`, из-за чего интерфейс мог выглядеть зависшим. Теперь используется безопасное определение состояния по папкам.
