# GTA3 IMG Switcher v1.0.0

First stable public release.

## Included
- English and Russian interface
- Custom profile names
- Fast gta3.img switching
- Active-profile detection
- GTA process detection
- Local logs and diagnostics
- FAQ and troubleshooting documentation
- Safe rollback protection

## Important
Always keep a backup of important modded files.
The application never uploads logs automatically.
